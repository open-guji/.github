# 📜 开源古籍 (Open-Guji)
**“让科技赋予古籍数字生命”**

欢迎来到开源古籍组织。我们致力于通过现代信息技术（AI、OCR、NLP、数字出版）对传统古籍进行数字化存证、整理与活化利用，构建开放、共享的古籍数字基础设施。

---

## 🌟 组织愿景
在数字时代，古籍不应仅存在于藏书楼。我们希望通过技术手段：
- **数字化重塑**：提高古籍 OCR 识别精度与排版还原度。
- **智能化检索**：实现基于语义的古籍内容检索与知识图谱构建。
- **开放化协作**：降低古籍研究门槛，让开发者与学者共同参与整理。

---

## 🛠️ 核心项目 (Repositories)
- **[luatex-cn](https://github.com/open-guji/luatex-cn)**: 基于 LuaTeX 的中文古籍排版引擎支持。
- **guji-resource-index**: 古籍资源网站索引。
- **[guji-platform](https://github.com/open-guji/guji-platform)**: 古籍整理平台。（封闭开发中）
- **[kaiyuanguji-web](https://github.com/open-guji/kaiyuanguji-web)**: 维护www.kaiyuanguji.com网站的代码。
